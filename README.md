# SQPaint

**SQPaint** — настольный растровый графический редактор на Python и PyQt6. Приложение поддерживает работу со слоями, базовые инструменты рисования, сохранение проектов в SQLite, экспорт изображений и настройку интерфейса.

## Возможности

### Работа с проектами
- Создание нового проекта с заданными параметрами холста.
- Открытие существующего проекта и продолжение работы с ним.
- Сохранение изменений в файл проекта.
- Стартовое окно с недавними проектами и быстрым доступом к созданию или открытию проекта.
- Учёт недавних проектов для быстрого переключения между ними.
- Предупреждение о несохранённых изменениях при закрытии или выполнении соответствующих операций.

### Рисование
- **Кисть** — рисование выбранным цветом и настройка толщины линии.
- **Ластик** — удаление пикселей на активном слое.
- **Заливка** — заполнение области цветом.
- **Фигуры (Shapes)** — прямоугольник, эллипс и звезда. Эллипс может иметь произвольные пропорции.
- Выбор цвета через стандартный диалог Qt.
- Отмена и повтор действий.

### Слои
- Создание и удаление слоёв.
- Выбор активного слоя.
- Изменение названия слоя.
- Изменение цвета элемента слоя в панели.
- Переключение видимости слоёв.
- Отображение результата с учётом порядка и видимости слоёв.

### Интерфейс и настройки
- Настраиваемая тема оформления, применяемая в том числе к стартовому окну и панели слоёв.
- Локализация интерфейса.
- Настройки приложения сохраняются между запусками.
- Настройка интервала автоматического сохранения.
- Обучение основным функциям редактора в разделе **«Справка → Обучение»**.
- Стандартные сочетания клавиш для основных операций.

### Сохранение и журналирование
- Автоматическое сохранение проекта с настраиваемым интервалом.
- Хранение не более **5 резервных копий** проекта: при создании новых копий самые старые удаляются.
- Журналирование действий приложения в консоль и в таблицу `logs` текущего SQLite-проекта.
- В журнал записываются операции с проектом, слоями, холстом, файлами и настройками.

### Экспорт
- Экспорт результата работы в распространённые форматы изображений, включая PNG и JPEG.

## Технологии

| Технология | Назначение |
|---|---|
| Python | Основной язык приложения |
| PyQt6 | Графический интерфейс и работа с изображениями |
| SQLite (`sqlite3`) | Хранение проектов, слоёв и журнала действий |
| JSON | Настройки приложения |
| CSV | Список недавних проектов |
| PyInstaller | Сборка приложения в исполняемый файл |

Для работы с SQLite, JSON, CSV и датами используются стандартные модули Python.

## Формат проекта

Один файл `.sqlite` соответствует одному проекту SQPaint. В базе данных хранятся параметры холста, слои и журнал действий.

Основные таблицы:

### `project`
Содержит общую информацию о проекте:
- `id` — идентификатор записи;
- `name` — название проекта;
- `width`, `height` — размеры холста;
- `created_at` — дата создания.

### `layers`
Содержит данные слоёв:
- `id` — идентификатор слоя;
- `name` — название;
- `z_order` — порядок отображения;
- `visible` — признак видимости;
- `pixels` — изображение слоя в виде PNG-данных (BLOB).

### `logs`
Хранит журнал событий проекта:
- `id` — идентификатор записи;
- `log` — описание события;
- `created_at` — дата и время события.

Параметры проекта не дублируются в каждой записи слоя: размеры холста хранятся на уровне проекта.

## Установка и запуск из исходного кода

Требуется установленный Python и pip.

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/RolicsVin/sqpaint.git
   cd sqpaint
   ```

2. Создайте и активируйте виртуальное окружение:

   **Windows:**
   ```powershell
   python -m venv .venv
   .venv\\Scripts\\activate
   ```

   **Linux / macOS:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

3. Установите PyQt6:

   ```bash
   pip install PyQt6
   ```

4. Запустите приложение:

   ```bash
   python main.py
   ```

Если в проекте используется файл зависимостей `requirements.txt`, зависимости можно установить командой `pip install -r requirements.txt`.

## Сборка для Windows

Для сборки в EXE используется PyInstaller:

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean --windowed --onedir --name SQPaint --icon icon.ico main.py
```

Готовая сборка появится в каталоге `dist/SQPaint/`. Режим `--onedir` размещает исполняемый файл и необходимые библиотеки рядом, а не упаковывает всё в один EXE.

## Архитектурные принципы

Проект разделяет пользовательский интерфейс, бизнес-логику, инструменты рисования и сервисы приложения. Главное окно отвечает за координацию компонентов, а специализированные модули — за свои отдельные задачи. Такой подход упрощает сопровождение и расширение редактора и помогает избегать концентрации всей логики в одном классе.

## Горячие клавиши

В редакторе предусмотрены стандартные сочетания клавиш для основных операций, в том числе:
- `Ctrl + S` — сохранить проект;
- `Ctrl + Z` — отменить действие;
- `Ctrl + Y` — повторить действие.

## Статус проекта

Основной функционал редактора реализован. Репозиторий содержит исходный код учебного проекта SQPaint.
