# SQPaint

**SQPaint** — настольный растровый графический редактор на Python и PyQt6. Приложение поддерживает работу со слоями, базовые инструменты рисования, сохранение проектов в SQLite, экспорт изображений и настройку интерфейса.

## Возможности

### Работа с проектами
- Создание нового проекта с заданными параметрами холста.
- Открытие существующего проекта и продолжение работы с ним.
- Сохранение изменений в файл проекта.
- Стартовое окно с недавними проектами и быстрым доступом к созданию или открытию проекта.
- Учёт недавних проектов для быстрого переключения между ними.
- Предупреждение о несохранённых изменениях при закрытии или выполнении соответствующих операций.

### Рисование
- **Кисть** — рисование выбранным цветом и настройка толщины линии.
- **Ластик** — удаление пикселей на активном слое.
- **Заливка** — заполнение области цветом.
- **Фигуры (Shapes)** — прямоугольник, эллипс и звезда. Эллипс может иметь произвольные пропорции.
- **Обрезка** — инструмент для обрезки изображения.
- Выбор цвета через стандартный диалог Qt.
- Отмена и повтор действий.

### Слои
- Создание и удаление слоёв.
- Выбор активного слоя.
- Изменение названия слоя.
- Изменение цвета элемента слоя в панели.
- Переключение видимости слоёв.
- Отображение результата с учётом порядка и видимости слоёв.

### Интерфейс и настройки
- Настраиваемая тема оформления, применяемая в том числе к стартовому окну и панели слоёв.
- Локализация интерфейса.
- Настройки приложения сохраняются между запусками.
- Настройка интервала автоматического сохранения.
- Обучение основным функциям редактора в разделе **«Справка → Обучение»**.
- Стандартные сочетания клавиш для основных операций.

### Сохранение и журналирование
- Автоматическое сохранение проекта с настраиваемым интервалом.
- Хранение не более **5 резервных копий** проекта: при создании новых копий самые старые удаляются.
- Журналирование действий приложения в консоль и в таблицу `logs` текущего SQLite-проекта.
- В журнал записываются операции с проектом, слоями, холстом, файлами и настройками.

### Экспорт
- Экспорт результата работы в распространённые форматы изображений, включая PNG и JPEG.

## Технологии

| Технология | Назначение |
|---|---|
| Python | Основной язык приложения |
| PyQt6 | Графический интерфейс и работа с изображениями |
| SQLite (`sqlite3`) | Хранение проектов, слоёв и журнала действий |
| JSON | Настройки приложения |
| CSV | Список недавних проектов |
| PyInstaller | Сборка приложения в исполняемый файл |

Для работы с SQLite, JSON, CSV и датами используются стандартные модули Python.

### Корневые файлы
- **`main.py`** — точка входа. Создаёт приложение Qt, загружает необходимые настройки и запускает стартовый интерфейс.
- **`requirements.txt`** — список внешних Python-зависимостей.
- **`icon.ico`, `logo.png`** — иконка приложения и графический логотип.
- **`test_project.sqlite`** — тестовый файл проекта SQLite.

### `core/` — ядро приложения
Содержит модели данных и общую логику, не привязанную напрямую к конкретным окнам интерфейса.
- **`models.py`** — модели проекта и слоёв.
- **`database.py`** — создание и обслуживание SQLite-базы: сохранение и загрузка проекта, работа со слоями и журналом.
- **`exporter.py`** — экспорт итогового изображения в графические форматы.
- **`image_utils.py`** — преобразование изображений и вспомогательные операции с ними.
- **`history.py`** — данные и логика истории изменений документа.
- **`localization.py`** — словари и базовые механизмы локализации интерфейса.
- **`time_utils.py`** — общие функции работы с датой и временем.
- **`__init__.py`** — инициализация пакета и экспорт используемых компонентов ядра.

### `qtools/` — инструменты рисования
Содержит отдельные классы инструментов, работающих с холстом.
- **`base.py`** — базовый интерфейс инструмента.
- **`brush.py`** — кисть.
- **`eraser.py`** — ластик.
- **`fill.py`** — заливка области.
- **`shapes.py`** — построение геометрических фигур.
- **`crop.py`** — обрезка изображения.

### `services/` — сервисы приложения
Отвечает за вспомогательные операции и хранение пользовательских данных, не относящиеся к отрисовке интерфейса.
- **`autosave.py`** — создание и ротация резервных копий проекта.
- **`logger.py`** — централизованная регистрация событий приложения с выводом в консоль и сохранением в журнал проекта.
- **`recent_projects.py`** — ведение списка недавно открытых проектов.
- **`settings.py`** — чтение и сохранение пользовательских настроек.
- **`webcam.py`** — вспомогательная работа с веб-камерой.

### `ui/` — пользовательский интерфейс
Содержит окна, виджеты и контроллеры, которые связывают интерфейс с логикой приложения.
- **`main_window.py`** — главное окно редактора и сборка основных элементов интерфейса.
- **`start_window.py`** — стартовое окно: создание проекта, открытие файла и список недавних проектов.
- **`canvas.py`** — виджет холста и обработка взаимодействия с ним.
- **`canvas_view.py`** — представление холста в рабочей области.
- **`layers_panel.py`** — панель управления слоями.
- **`tool_bar.py`** — панель выбора инструмента и его параметров.
- **`dialogs.py`** — диалоговые окна приложения, включая настройки и обучение.
- **`document_controller.py`** — операции над документом: создание, открытие, сохранение и закрытие проекта.
- **`history_controller.py`** — связь истории изменений с интерфейсом и командами отмены/повтора.
- **`localization_controller.py`** — применение выбранного языка к элементам интерфейса.
- **`menu_controller.py`** — создание и обработка команд главного меню.
- **`preferences_controller.py`** — применение пользовательских настроек к интерфейсу и компонентам приложения.
- **`autosave_controller.py`** — управление запуском и настройкой периодического автосохранения со стороны интерфейса.
- **`view_manager.py`** — управление отображением рабочей области и её компонентов.
- **`zoom_control.py`** — управление масштабом просмотра холста.
- **`rounded_widget.py`** — базовый переиспользуемый виджет со скруглённым оформлением.
- **`selfie_dialog.py`** — диалог, связанный с получением изображения с веб-камеры.

## Формат проекта

Один файл `.sqlite` соответствует одному проекту SQPaint. В базе данных хранятся параметры холста, слои и журнал действий.

Основные таблицы:

### `project`
Содержит общую информацию о проекте:
- `id` — идентификатор записи;
- `name` — название проекта;
- `width`, `height` — размеры холста;
- `created_at` — дата создания.

### `layers`
Содержит данные слоёв:
- `id` — идентификатор слоя;
- `name` — название;
- `z_order` — порядок отображения;
- `visible` — признак видимости;
- `pixels` — изображение слоя в виде PNG-данных (BLOB).

### `logs`
Хранит журнал событий:
- `id` — идентификатор записи;
- `log` — описание события;
- `created_at` — дата и время события.

Параметры проекта не дублируются в каждой записи слоя: размеры холста хранятся на уровне проекта.

## Установка и запуск из исходного кода

Требуется установленный Python и pip.

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/RolicsVin/sqpaint.git
   cd sqpaint
   ```

2. Создайте и активируйте виртуальное окружение:

   **Windows:**
   ```powershell
   python -m venv .venv
   .venv\\Scripts\\activate
   ```

   **Linux / macOS:**
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите приложение:

   ```bash
   python main.py
   ```

## Сборка для Windows

Для сборки в EXE используется PyInstaller:

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean --windowed --onedir --name SQPaint --icon icon.ico main.py
```

Готовая сборка появится в каталоге `dist/SQPaint/`. Режим `--onedir` размещает исполняемый файл и необходимые библиотеки рядом, а не упаковывает всё в один EXE.

## Архитектурные принципы

Проект разделяет пользовательский интерфейс, бизнес-логику, инструменты рисования и сервисы приложения. Главное окно отвечает за координацию компонентов, а специализированные модули — за свои отдельные задачи. Контроллеры в `ui/` выносят отдельные сценарии работы из главного окна. Такой подход упрощает сопровождение и расширение редактора и помогает избегать концентрации всей логики в одном классе.

## Горячие клавиши

В редакторе предусмотрены стандартные сочетания клавиш для основных операций, в том числе:
- `Ctrl + S` — сохранить проект;
- `Ctrl + Z` — отменить действие;
- `Ctrl + Y` — повторить действие.

## Статус проекта

Основной функционал редактора реализован. Репозиторий содержит исходный код учебного проекта SQPaint.
