# SQPaint

## Тема проекта
Растровый редактор


## Описание проекта
**Название:** SQPaint
Paint с графическим интерфейсом на PyQt6. Рабочий формат(Файл в котором программа будет хранить данные изображений) - .sqlite

Как конкретно будет хранится изображение в формате .sqlite?
Главная идея: один файл .sqlite = один проект paint. Внутри файла лежат таблицы — project, layers и logs.

**Устройство таблицы Project внутри(Столбцы):**
id - INTEGER PRIMARY KEY CHECK (id = 1).
name - TEXT.
width - INTEGER.
height - INTEGER.
created_at - TEXT.

**Устройство таблицы Layers внутри(Столбцы):**
id - INTEGER PRIMARY KEY.
name - TEXT.
z_order - INTEGER.
visible - INTEGER.
pixels - BLOB (изображение слоя в формате PNG в виде байтов).

**Устройство таблицы Logs внутри(Столбцы):**
id - INTEGER PRIMARY KEY.
log - TEXT.
created_at - TEXT.

То есть, слои будут хранится в Layers и для каждого слоя свой z_order и visible.
Дублирования данных тоже нет, то есть, например, нет необходимости хранить width и height для каждого слоя — всё это вынесено в отдельную таблицу Project. Таблица Logs будет хранить историю для отладки.

Также программа будет хранить свои настройки в json файле и хранить список проектов в csv файле(Название проекта;путь к проекту;дата создания), чтобы можно было между ними быстро переключаться.

Будут использованы стандартные диалоги, например: закрытие программы без сохранения или выбор цвета(открывается небольшое окошко в котором пользователю предлагается выбрать цвет кисти).


## Актуальность проекта
Растровые редакторы остаются одним из самых востребованных классов программ: ими пользуются и при обучении, и в быстрой работе с графикой. Однако большинство редакторов хранят изображение либо в «плоском» формате (PNG, JPG), где теряется структура работы, либо в сложных закрытых форматах (PSD и подобные), которые трудно читать и анализировать без специального ПО.
SQPaint предлагает другой подход: проект хранится в базе данных SQLite. Один файл содержит и слои, и настройки холста, и журнал действий. Такой формат переносится одним файлом, читается стандартными средствами любого языка программирования, поддерживает целостность данных и не требует отдельного сервера. Проект также показывает практическое применение реляционной базы данных за пределами привычных задач «таблица с записями».


## Планируемый функционал
Можно создавать проекты, сохранять, загружать, редактировать.
Можно рисовать на холсте, ластик, менять размер кисти, цвет, делать заливку,
делать примитивные формы(Как в базовом paint всякие прямоугольники, кружочки).

При старте программа встречает пользователя листом с недавними проектами.
Можно выбрать из предложенного списка или выбрать пункты: Создать новый проект, открыть существующий проект. В списке проектов будут отображаться даты их создания(datetime).

Также работа со слоями: добавление, удаление, переключение, скрытие слоёв.

Будет отдельный файл, в котором программа будет хранить недавние проекты(csv).
Фомрат сохранения недавних файлов в таблице csv будет такой: имя проекта;путь к проекту;дата создания
Экспорт изображения в png/jpg и другие форматы изображений.

Программа будет делать авто-сохранения, копируя текущий файл и добавляя к нему суффикс с числом. Хранить, будет, только последние 5 копий, всё что старое и превышает лимит — удалятся.


## Планируемая структура проекта
sqpaint/
├── main.py                  # точка входа: создаёт QApplication и стартовое окно
├── core/                    # логика, без интерфейса
│   ├── models.py            # классы Layer и Project
│   ├── database.py          # вся работа с sqlite3
│   ├── image_utils.py       # QImage <-> bytes (PNG), склейка слоёв
│   └── exporter.py          # экспорт в PNG/JPG и др.
├── services/                # вспомогательные вещи вокруг приложения
│   ├── settings.py          # json-настройки
│   ├── recent_projects.py   # csv со списком проектов
│   └── autosave.py          # автосохранение (backup)
├── tools/                   # инструменты рисования
│   ├── base.py              # базовый класс Tool
│   ├── brush.py
│   ├── eraser.py
│   ├── fill.py
│   └── shapes.py
└── ui/                      # всё, что видит пользователь
    ├── start_window.py      # лист недавних проектов
    ├── main_window.py       # главное окно редактора
    ├── canvas.py            # холст
    ├── layers_panel.py      # список слоёв
    └── dialogs.py           # диалоги (цвет, «сохранить?», новый проект)

## Примечания
Будут использоваться технологии:
1. **PyQt6** — графический интерфейс, рисование.
2. **sqlite3** — сохранение, запись, чтение.
3. **Json** – настройки программы.
4. **csv файлы** — для хранения недавних проектов.
5. **datetime** – дата создания проекта, логи.
